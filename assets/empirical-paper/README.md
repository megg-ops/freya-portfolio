# empirical-paper 项目素材

此目录用于个人求职网站中的 `empirical-paper` 项目展示。

## 文件

- `cover-v2.webp`：推荐用于网页的新版封面，1280 × 801，日系动漫水彩风格；
- `cover.png`：第一版机制草图，保留用于版本对照，不建议继续用于网页；
- `content.md`：卡片、封面和详情页可直接使用的文案；
- `image-prompt.md`：封面设计说明与最终生图提示词。

## 封面机制映射

- 原始表格纸张：用户提供的 CSV/XLSX 数据；
- 带刻度的检验台：脚本执行全量、确定性数据审计；
- 上方半透明批注层：模型只补充变量语义与研究语境；
- 陶土色确认压章装置：关键歧义必须由用户确认；
- 上锁的中央证据柜：`results.json` 作为唯一数字真源；
- 三道检验门：数字一致性、DOCX 完整性与最终质量门禁；
- 右侧论文和材料：论文成品、分析代码、审计报告与复现证据。

视觉上沿用个人网站“日光首屏 A”的米纸、水彩、铅笔、苔绿和陶土色，但不重复树木与生长构图。新版采用日系动漫背景水彩的轻线稿与清透色块，人工确认由陶土色压章装置表达，不出现写实人物或真人手部。
