# 品牌站插画生成提示词（统一画风）

> 目标：延续现有三张图的画风（avatar.png / shiba-companion.png / about-freya-shiba-laptop.png）
> 适用工具：即梦 / Midjourney / nano banana 均可（MJ 请把中文翻成英文）
> 生成后按「文件名」列命名，放进 `website/assets/`，网页会自动启用新图

## 统一风格前缀（每条提示词开头都带上）

```
手绘动漫插画，黑白线条 + 柔和水彩平涂上色，奶油米白色干净背景。
人物：年轻女孩，黑色高马尾，戴黑色棒球帽（帽前有灰色手写体"simple"字样），
黑色细条纹露肩上衣，极细黑线勾勒，皮肤保持留白不上色（黑白漫画感）。
柴犬：橙色水彩柴犬，大圆脸，白色口吻与胸毛，棕色豆豆眉，粉色腮红，卷尾巴。
整体气质：安静、温柔、有呼吸感，水彩晕染边缘。
```

## 负面约束（每条结尾都带上）

```
不要写实，不要3D渲染，不要照片感，不要厚涂油画，不要复杂场景背景，
不要给女孩皮肤上色，不要改变帽子上"simple"字样。
```
