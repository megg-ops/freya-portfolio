# 树 · 美术资产生成提示词

> 现状：`assets/tree-spring-full.svg` 和 `tree-spring-up.svg` 是**程序生成的矢量占位树**，
> 骨架（根／干／分枝）质量可用，树冠只到「能看」的水平，达不到水彩插画的审美天花板。
> 三个首屏方案对树冠质量的依赖度：**B（仰视）最高 > A（地平线剖面）中 > C（标本页）最低**。
>
> 如果要把树换成真美术资产，用下面的提示词在即梦 / MJ / nano banana 生成，
> 生成后**必须抠成透明背景 PNG**（现有素材全是米白底 RGB，直接用会出现白方块）。
> 抠图脚本见本次会话的做法：线稿闭运算 → `binary_fill_holes` → 最大连通块 → 边缘去色污染。

## 统一风格前缀（沿用现有画风）

```
手绘动漫插画，黑白线条 + 柔和水彩平涂上色，奶油米白色干净背景。
水彩晕染边缘，颜色有深浅层叠和边缘沉积，留白充足。
整体气质：安静、温柔、有呼吸感。
```

## 负面约束

```
不要写实，不要3D渲染，不要照片感，不要厚涂油画，
不要把树冠画成一团均匀的绿色色块，不要圆形色块拼贴的树冠，
不要光秃的枝条，不要对称规整的树形，不要卡通剪贴画感。
```

## 1. tree-spring-full.png ｜ 整株标本树（A 和 C 都用得上）

**构图**：竖版 3:4，整株居中，四周留白

```
[风格前缀] 一棵完整的落叶乔木，连根拔起的植物标本视角：
可以清楚看到发达的根系向下向两侧铺开、粗壮的主干、三到四级分枝、
以及春天新发的淡绿色树冠。
树冠是层叠的水彩绿（深绿打底、中绿、嫩绿高光三层），
团块之间有真实的叶隙，能从缝里看到里面的枝条。
树冠轮廓不规则、有凹口，边缘能看出是叶子而不是色块。
根系用赭石棕，比树冠淡。
[负面约束]
```

## 2. tree-spring-canopy.png ｜ 仰视树冠（B 专用）

**构图**：横版 16:9，树冠占满上方并从画面顶部溢出

```
[风格前缀] 从树下抬头仰望的视角：粗壮的树干从画面底部中央升起，
向上分出主枝，树冠在头顶铺开并从画面顶边溢出。
阳光从树冠的叶隙里漏下来，形成明亮的光斑和半透明的嫩绿。
能看到枝条在叶团之间穿插的结构。
[负面约束]
```

## 3. 备选：单独的树冠叶团笔刷（可选）

如果只想换掉树冠、保留现有骨架，生成 4～6 个独立的叶团：

```
[风格前缀] 单独一团春天的树叶，水彩画法，深浅三层绿色层叠，
边缘不规则有凹口能看出叶片形状，透明背景，四周留白。
[负面约束]
```

## 交付要求

- 输出 PNG，长边 ≥ 2000px
- **必须带透明通道**；若工具只能出米白底，交给 Argo 抠图
- 命名照上面的文件名放进 `website/assets/`
- 换资产后需要重新量一次宽高比和「树干基部位置」，更新首屏 HTML 里的
  `--tree-ar` / `--tree-base` 两个变量，以及四个项目的锚点百分比
